A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 Si bebidas = ["agua", "jugo", "té"], ¿qué muestra print(bebidas[1])?

Las posiciones de una lista empiezan en 0: bebidas[0] es "agua" y bebidas[1] es "jugo".

2 Si colores = ("rojo", "verde"), ¿qué ocurre al ejecutar colores[0] = "azul"?

Una tupla es inmutable: se puede leer (colores[0]) pero no cambiar. Si el dato debe cambiar, corresponde una lista.

3 ¿Qué método devuelve los pares clave-valor para recorrerlos con for clave, valor in ...?

.items() entrega dos valores por vuelta: la clave y su valor. .keys() y .values() entregan solo una parte.

4 En este código, ¿cuándo se ejecuta la función mostrar_tabla(7)?

ventana = Tk()

def mostrar_tabla(n):
    print("Tabla del", n)

Button(ventana, text="7", command=mostrar_tabla(7))

Los paréntesis de mostrar_tabla(7) ejecutan la función en el momento de crear el botón. Para que se ejecute en cada clic hay que escribir command=lambda: mostrar_tabla(7).

5 En la conexión con MySQL, ¿cuál es la diferencia entre commit() y close()?

commit() confirma la operación (por ejemplo un INSERT) y la deja guardada. close() cierra la conexión con la base cuando terminamos.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

materias = ["Matemática", "Lengua", "Historia"]
materias.append("Arte")
print(len(materias))
print(materias[1])

append("Arte") deja 4 elementos y materias[1] sigue siendo "Lengua". La salida es 4 Lengua.

7 ¿Qué muestra este programa?

precios = {"pan": 100, "leche": 200}
for producto, precio in precios.items():
    print(producto, precio)

.items() entrega la clave y el valor en cada vuelta, en el orden en que se cargaron. La salida es pan 100 leche 200.

8 ¿Qué muestra este programa?

limites = (10, 99)
minimo, maximo = limites
print(minimo)
print(maximo)

El desempaquetado asigna 10 a minimo y 99 a maximo. La salida es 10 99.

9 ¿Qué muestra este programa?

notas = [8, 7, 9]
suma = 0
for n in notas:
    suma += n
print(suma)

El acumulador suma 8 + 7 + 9. La salida es 24.

Actividades cortas

3 actividades · 1 punto cada una · dos de Tkinter y una teórica de base de datos.

10 Tkinter · un Label en tres pasos. Cada elemento que crees debe cumplir como mínimo tres cosas: crearlo, configurarlo y alinearlo. Por ejemplo, un Label se crea con Label(...), se configura con bg=, font= o .config(...), y se alinea con .pack().

Mostrá un Label que diga "Hola", con fondo amarillo y fuente ("Arial", 20). Cerrá con mainloop(). Podés resolverlo de dos formas: todo en una sola línea o repartido en tres líneas.

Ver las dos soluciones de referencia

Forma 1 · todo en una línea:

from tkinter import *

ventana = Tk()
Label(ventana, text="Hola", bg="yellow", font=("Arial", 20)).pack()
ventana.mainloop()

Forma 2 · repartido en tres líneas:

from tkinter import *

ventana = Tk()
etiqueta = Label(ventana, text="Hola")
etiqueta.config(bg="yellow", font=("Arial", 20))
etiqueta.pack()
ventana.mainloop()

11 Tkinter · una función. Escribí def cambiar(): que cambie el texto del label a "¡Apretaste!" con etiqueta.config(text=...). Después creá un Button con command=cambiar (sin paréntesis) y cerrá con mainloop().

Ver una solución de referencia 
from tkinter import *

ventana = Tk()
