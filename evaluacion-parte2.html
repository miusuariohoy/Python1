A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 Si cursos = ["1A", "2A", "3A"], ¿qué muestra print(cursos[1])?

Las posiciones de una lista empiezan en 0: cursos[0] es "1A" y cursos[1] es "2A".

2 Si punto = (120, 140), ¿qué ocurre al ejecutar punto[0] = 200?

Una tupla es inmutable: se puede leer (punto[0]) pero no cambiar. Si el dato debe cambiar, corresponde una lista.

3 ¿Qué método devuelve los pares clave-valor para recorrerlos con for clave, valor in ...?

.items() entrega dos valores por vuelta: la clave y su valor. .keys() y .values() entregan solo una parte.

4 En un botón de Tkinter, ¿por qué se usa command=lambda: mostrar_tabla(7) en lugar de command=mostrar_tabla(7)?

Sin lambda, los paréntesis ejecutan la función en el momento de crear el botón. lambda fabrica una mini-función que Tkinter llama recién con el clic.

5 ¿Cuál de estas afirmaciones sobre la Parte 2 es correcta?

play(-1) repite para siempre. coords() mueve el objeto, commit() confirma cambios (INSERT) y un Text se borra con delete("1.0", END).

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

cursos = ["1A", "2A", "3A"]
cursos.append("4A")
print(len(cursos))
print(cursos[1])

append("4A") deja 4 elementos y cursos[1] sigue siendo "2A". La salida es 4 2A.

7 ¿Qué muestra este programa?

alumno = {"nombre": "Ana", "curso": "3A"}
print(alumno["curso"])
print(alumno.get("turno", "sin turno"))

alumno["curso"] devuelve "3A"; como la clave "turno" no existe, .get() devuelve el valor por defecto "sin turno".

8 ¿Qué muestra este programa?

punto = (120, 140)
x, y = punto
print(x)
print(y)

El desempaquetado asigna 120 a x y 140 a y. La salida es 120 140.

9 ¿Qué muestra este programa?

notas = [8, 7, 9]
suma = 0
for n in notas:
    suma += n
print(suma)

El acumulador suma 8 + 7 + 9. La salida es 24.

10 Escribí mostrar_tabla(n): debe borrar un widget Text con delete("1.0", END), recorrer range(1, 11) e insertar cada línea f"{n}*{i}={n*i}" con insert(END, ... + "\n"). Después creá un Button con command=lambda: mostrar_tabla(7) y cerrá con mainloop().

Ver una solución de referencia 
from tkinter import *

ventana = Tk()
texto_tabla = Text(ventana)
texto_tabla.pack()

def mostrar_tabla(n):
    texto_tabla.delete("1.0", END)
    for i in range(1, 11):
        texto_tabla.insert(END, f"{n}*{i}={n*i}" + "\n")

Button(ventana, text="7", command=lambda: mostrar_tabla(7)).pack()
ventana.mainloop()

11 Escribí conectar() que devuelva mysql.connector.connect(...) con host, user, password y database. Después escribí guardar() que lea el nombre con .get(), ejecute INSERT INTO alumnos (nombre, curso) VALUES (%s, %s) con cursor.execute(sql, (nombre, curso)), confirme con commit(), cierre con close() y avise con messagebox.showerror(...) si algo falla dentro de try / except.

Ver una solución de referencia 
import mysql.connector
from tkinter import messagebox

def conectar():
    return mysql.connector.connect(
        host="localhost",
        user="root",
        password="",
        database="escuela"
    )

def guardar():
    nombre = entrada_nombre.get()
    curso = combo_curso.get()
    try:
        cnx = conectar()
        cursor = cnx.cursor()
        sql = "INSERT INTO alumnos (nombre, curso) VALUES (%s, %s)"
        cursor.execute(sql, (nombre, curso))
        cnx.commit()
        cnx.close()
    except:
        messagebox.showerror("Error", "No se pudo conectar a la base")
