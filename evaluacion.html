A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué estructura representa un if / elif / else?

El if elige qué bloque ejecutar según una condición: es una estructura de selección.

2 ¿Qué tipo de dato devuelve input()?

input() siempre devuelve texto (str). Si necesitás un número, convertilo con int() o float().

3 ¿Qué valores recorre for i in range(1, 6):?

range(inicio, fin) incluye el inicio y excluye el fin: llega hasta 5.

4 Si notas = [8, 6, 10], ¿cuánto vale notas[0]?

Los índices de una lista empiezan en 0: notas[0] es el primer elemento, 8.

5 ¿Para qué sirve definir una función?

Una función agrupa instrucciones bajo un nombre y permite reutilizarlas sin repetir el código.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

x = 5
if x > 3:
    print("mayor")
else:
    print("menor")

Como 5 es mayor que 3, se ejecuta el if: la salida es mayor.

7 ¿Qué muestra este programa?

total = 0
for i in range(1, 5):
    total += i
print(total)

Suma 1 + 2 + 3 + 4. El range(1, 5) no incluye el 5: la salida es 10.

8 ¿Qué muestra este programa?

contador = 3
while contador > 0:
    print(contador)
    contador -= 1

El bucle imprime 3, luego 2 y luego 1. La salida es 3 2 1 (uno por línea).

9 ¿Qué muestra este programa?

notas = [7, 4, 9]
print(notas[1])
print(len(notas))

notas[1] es 4 y len(notas) es 3. La salida es 4 3 (una línea cada uno).

C

Ejercicios de código

2 programas · 1,5 puntos cada uno · se corrige la estructura del código.

10 Escribí un programa que pida el nombre y la edad de una persona, convierta la edad a entero y muestre un mensaje como: Hola Ana, tenés 17 años. Usá un f-string.

Ver una solución de referencia 
nombre = input("Nombre: ")
edad = int(input("Edad: "))
print(f"Hola {nombre}, tenés {edad} años")

11 Escribí un programa que muestre los números del 1 al 10 (uno por línea) y al final imprima la suma total, que debe dar 55. Usá un acumulador.

Ver una solución de referencia 
suma = 0
for i in range(1, 11):
    print(i)
    suma += i
print("Suma total:", suma)
