A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué valores recorre for i in range(1, 6):?

range(inicio, fin) incluye el inicio y excluye el fin: llega hasta 5.

2 ¿Cuántas vueltas da for i in range(3):?

range(3) equivale a range(0, 3): genera 0, 1 y 2 (tres vueltas).

3 Querés mostrar 5, 4, 3, 2 y 1 con un while. ¿Qué condición usarías si el contador arranca en 5 y baja de a uno?

Si el contador baja, la condición debe permitir los valores 5, 4, 3, 2 y 1: i >= 1. Cuando llega a 0, el ciclo termina.

4 ¿Cómo se define una función sin parámetro?

Se usa def, el nombre, los paréntesis vacíos y dos puntos. En Python no existe function.

5 No sabés cuántos números va a escribir el usuario: el programa debe sumar hasta que escriba 0. ¿Qué bucle conviene usar?

Cuando no se sabe cuántas vueltas habrá y el final depende de una condición (el centinela 0), se usa while.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

for i in range(3):
    print(i)

range(3) genera 0, 1 y 2. La salida es 0 1 2 (uno por línea).

7 ¿Qué muestra este programa?

suma = 0
for i in range(1, 5):
    suma += i
print(suma)

Suma 1 + 2 + 3 + 4. El range(1, 5) no incluye el 5: la salida es 10.

8 ¿Qué muestra este programa?

i = 3
while i > 0:
    print(i)
    i -= 1

El bucle imprime 3, luego 2 y luego 1. La salida es 3 2 1 (uno por línea).

9 ¿Qué muestra este programa?

def saludar():
    print("Hola")

saludar()
saludar()

La función se llama dos veces y cada llamada muestra Hola: la salida es hola hola.
