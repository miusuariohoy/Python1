A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué tipo de dato es 3.5 en Python?

Los números con decimales se representan con float. Los enteros usan int.

2 ¿Qué operador devuelve el resto de una división?

% es el módulo: devuelve el resto. // hace la división entera y ** calcula potencias.

3 ¿Qué estructura conviene para elegir entre tres casos excluyentes?

if / elif / else permite evaluar varias condiciones en orden y ejecutar una sola rama: es una estructura de selección múltiple.

4 Si notas = [7, 8, 9], ¿qué devuelve len(notas)?

len() devuelve la cantidad de elementos de la lista, no su suma ni sus valores: la lista tiene 3 elementos.

5 ¿Con qué palabra clave se define una función en Python?

En Python una función se declara con def, por ejemplo def saludar():.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

a = 7
b = 2
print(a // b)
print(a % b)

7 // 2 es 3 (división entera) y 7 % 2 es 1 (resto). La salida es 3 1.

7 ¿Qué muestra este programa?

edad = 15
if edad >= 18:
    print("mayor")
elif edad >= 13:
    print("adolescente")
else:
    print("menor")

15 no es mayor ni igual a 18, pero sí es mayor o igual a 13: se ejecuta el elif. La salida es adolescente.

8 ¿Qué muestra este programa?

contador = 1
while contador <= 4:
    print(contador * 2)
    contador += 1

El bucle multiplica por 2 los valores 1, 2, 3 y 4. La salida es 2 4 6 8 (uno por línea).

9 ¿Qué muestra este programa?

def doble(n):
    return n * 2

print(doble(5) + 1)

doble(5) devuelve 10 y luego se le suma 1. La salida es 11.

Ver una solución de referencia 
temp = int(input("Temperatura: "))
if temp < 10:
    print("Frío")
else:
    print("Templado")
