A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué módulo se importa para conectarse a MySQL desde Python?

El módulo que se usa en la guía es mysql.connector.

2 ¿Qué hace cursor.execute(consulta, valores)?

execute() envía la consulta a la base de datos con los valores de los %s.

3 ¿Cómo se confirman los cambios en la base de datos?

commit() guarda definitivamente los cambios. Sin él, se descartan.

4 ¿Qué marcador se usa para los valores en una consulta con execute()?

Se usan huecos %s y se pasan los valores en una tupla.

5 ¿Para qué sirve try / except en el formulario?

Si falla la conexión o la consulta, except permite mostrar un aviso con messagebox.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

consulta = "SELECT * FROM alumnos"
print(consulta)

La variable guarda ese texto y print lo muestra: SELECT * FROM alumnos.

7 ¿Qué muestra este programa?

valores = ("Ana",)
print(len(valores))

Es una tupla de un solo elemento: 1.

8 ¿Qué muestra este programa?

print("INSERT" + " INTO")

La concatenación une los dos textos: INSERT INTO.

9 ¿Qué muestra este programa?

accion = "commit"
print(accion.upper())

upper() devuelve COMMIT (se acepta en minúsculas).
