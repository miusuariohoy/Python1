A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuál es una función con parámetro?

La función con parámetro recibe un dato entre los paréntesis de la definición: def saludar(nombre):.

2 ¿Cuál es la diferencia principal entre print y return?

print() muestra; return entrega el valor para guardarlo o seguir calculando.

3 ¿Cuál conecta correctamente el botón con la función verificar?

En command= va el nombre de la función sin paréntesis. Con paréntesis se ejecuta una sola vez al crear el botón.

4 ¿Para qué se usa try / except?

try intenta; si ocurre un error, except lo atrapa y ejecuta una alternativa en lugar de cerrar el programa.

5 Necesitás un entero entre 1 y 10, incluidos los dos extremos. ¿Qué línea lo logra?

randint(a, b) incluye los dos extremos. Además, hay que escribir random.randint(...) después de importar el módulo.

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

def doble(n):
    return n * 2

print(doble(4))

La función devuelve 4 * 2 y print muestra el valor devuelto: 8.

7 ¿Qué muestra este programa?

def saludar(nombre):
    print("Hola", nombre)

saludar("Ana")

print separa los valores con un espacio: Hola Ana.

8 ¿Qué muestra este programa?

try:
    print(int("hola"))
except ValueError:
    print("error")

int("hola") produce un ValueError; el except lo atrapa y muestra error.

9 ¿Qué muestra este programa?

import random

elegido = random.choice(["Ana"])
print(elegido)

La lista tiene un solo elemento, así que choice siempre elige Ana.

Ver una solución de referencia

    return n * 2

resultado = doble(8)
print(resultado)

    numero = int(input("Número: "))
    print("Número válido")
