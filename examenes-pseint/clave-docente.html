Parte C · Soluciones (3 puntos)

Actividad 1 · Nombre y edad

Algoritmo EdadPersona
    Definir nombre Como Caracter;
    Definir edad Como Entero;
    Escribir "Ingresá el nombre:";
    Leer nombre;
    Escribir "Ingresá la edad:";
    Leer edad;
    Si edad >= 18 Entonces
        Escribir nombre, " es mayor de edad";
    Sino
        Escribir nombre, " es menor de edad";
    FinSi
FinAlgoritmo

Requisitos: algoritmo completo, nombre como Caracter, edad como Entero, dos lecturas, Si/Sino/FinSi, comparación con 18 y mensajes con el nombre.

Actividad 2 · Contar mayores de edad

Algoritmo ContarMayores
    Definir edad, mayores Como Entero;
    mayores <- 0;
    Escribir "Ingresá una edad (0 para terminar):";
    Leer edad;
    Mientras edad <> 0 Hacer
        Si edad >= 18 Entonces
            mayores <- mayores + 1;
        FinSi
        Escribir "Ingresá otra edad (0 para terminar):";
        Leer edad;
    FinMientras
    Escribir "Mayores de edad: ", mayores;
FinAlgoritmo

Requisitos: contador inicializado en 0, lectura antes del Mientras, condición de corte con 0, Si para edades de 18 o más, incremento del contador, nueva lectura dentro del bucle y salida del total.

Actividad 3 · SubProceso SumarHasta

SubProceso SumarHasta(limite)
    Definir i, suma Como Entero;
    suma <- 0;
    Para i <- 1 Hasta limite Con Paso 1 Hacer
        suma <- suma + i;
    FinPara
    Escribir "Total: ", suma;
FinSubProceso

Algoritmo SumaHastaCinco
    SumarHasta(5);
FinAlgoritmo

Requisitos: SubProceso SumarHasta(limite) y FinSubProceso, variables enteras, acumulador en 0, Para del 1 al límite, acumulación, salida del total y llamada SumarHasta(5) desde el algoritmo principal.

Actividad 1 · Producto y precio

Algoritmo PrecioProducto

Actividad 2 · Contar notas aprobadas

Algoritmo ContarAprobadas
    Definir nota Como Real;
    Definir aprobadas Como Entero;
    aprobadas <- 0;
    Escribir "Ingresá una nota (-1 para terminar):";
    Leer nota;
    Mientras nota <> -1 Hacer
        Si nota >= 6 Entonces
            aprobadas <- aprobadas + 1;
        FinSi
        Escribir "Ingresá otra nota (-1 para terminar):";
        Leer nota;
    FinMientras
    Escribir "Aprobadas: ", aprobadas;
FinAlgoritmo

Requisitos: contador inicializado en 0, lectura antes del Mientras, condición de corte con -1, Si para notas de 6 o más, incremento del contador, nueva lectura dentro del bucle y salida del total.

Actividad 3 · SubProceso SumarPares

SubProceso SumarPares(limite)
    Definir i, suma Como Entero;
    i <- 2;
    suma <- 0;
    Mientras i <= limite Hacer
        suma <- suma + i;
        i <- i + 2;
    FinMientras
    Escribir "Total: ", suma;
FinSubProceso

Algoritmo SumaParesHastaDiez
    SumarPares(10);
FinAlgoritmo

Requisitos: SubProceso SumarPares(limite) y FinSubProceso, variables enteras, i en 2, acumulador en 0, Mientras i <= limite, acumulación, avance de 2 en 2, salida del total y llamada SumarPares(10) desde el algoritmo principal.

Rúbrica de puntaje

Cómo se distribuyen los 10 puntos

ParteCriterioPuntaje
A · Opción múltiple1 punto por respuesta correcta; sin puntaje parcial.5
B · Salidas0,5 puntos por salida exacta. Se aceptan espacios o comas entre valores.2
C · Programas1 punto por actividad, distribuido entre los requisitos de estructura. Se otorga puntaje proporcional.3
Total10

Errores frecuentes

  • No declarar variables o declararlas con un tipo incorrecto.
  • Olvidar el FinSi, FinMientras, FinPara o FinSubProceso.
  • No inicializar el contador o el acumulador antes del bucle.
  • No volver a leer dentro del Mientras, lo que produce un bucle infinito.
  • Usar = en lugar de <- para asignar.
  • Comparar con = cuando se necesita <> (distinto).
  • No llamar al subproceso desde el algoritmo principal.
  • Confundir contador con acumulador: el contador suma 1; el acumulador suma un valor variable.

Observaciones para la corrección

  • Se aceptan nombres de variables equivalentes (por ejemplo, mayores, contador, total o cantidad) siempre que el rol sea correcto.
  • Se aceptan Caracter o Cadena para textos.
  • Se aceptan Mientras edad <> 0, Mientras edad != 0 o Mientras edad > 0 para el corte con 0.
  • Se aceptan Mientras nota <> -1, Mientras nota != -1 o Mientras nota >= 0 para el corte con -1.
  • El corrector revisa estructura con expresiones regulares; no ejecuta el pseudocódigo. Ante una solución alternativa válida, el docente puede revisar el código manualmente.
