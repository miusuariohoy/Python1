A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuáles son las tres estructuras básicas de la programación estructurada?

La programación estructurada se organiza con secuencia (una instrucción tras otra), selección (Si–Entonces) e iteración (Mientras / Para).

2 Para guardar el precio de un producto con decimales, ¿cuál declaración es correcta en PSeInt estricto?

Real almacena números con parte decimal. Entero solo guarda números sin decimales. La forma correcta es Definir nombre Como Tipo;.

3 ¿Qué ocurre cuando el programa ejecuta Leer edad;?

Leer es una instrucción de entrada: espera que el usuario escriba un dato y lo almacena en la variable. Para mostrar información se usa Escribir.

4 ¿Qué estructura conviene para mostrar un menú y repetirlo hasta que el usuario elija Salir?

El Mientras es un bucle indeterminado: se repite mientras la condición sea verdadera. El Para se usa cuando se conoce la cantidad de vueltas.

5 En la instrucción total <- total + precio;, ¿qué papel cumple total?

Un acumulador suma valores variables (total <- total + precio). Un contador suma una cantidad fija, normalmente 1 (c <- c + 1).

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir nota Como Real;
nota <- 5.5;
Si nota >= 6 Entonces
    Escribir "Aprobado";
Sino
    Escribir "Desaprobado";
FinSi

5.5 es menor que 6, así que la condición es falsa y se ejecuta la rama del Sino: la salida es Desaprobado.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
i <- 4;
Mientras i >= 1 Hacer
    Escribir i;
    i <- i - 1;
FinMientras

Muestra 4, luego 3, luego 2 y luego 1. Cuando i llega a 0, la condición i >= 1 es falsa y el bucle termina. La salida es 4 3 2 1.

8 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 2 Hasta 8 Con Paso 2 Hacer
    Escribir i;
FinPara

El Para comienza en 2, avanza de 2 en 2 y se detiene en 8 (incluido). La salida es 2 4 6 8.

9 ¿Qué muestra este algoritmo?

SubProceso MostrarDoble(numero)
    Escribir numero * 2;
FinSubProceso

Algoritmo Prueba
    MostrarDoble(6);
FinAlgoritmo

El subproceso recibe 6 en el parámetro numero y muestra 6 * 2 = 12. La salida es 12.

Cómo se corrige la Parte C

Cada actividad vale 1 punto y se evalúa con una lista de requisitos. Si falta un requisito, se descuenta la parte proporcional. El corrector revisa la estructura del pseudocódigo; no ejecuta el programa.

Antes de enviar

  • Declaré todas las variables con su tipo.
  • Cerré cada Si, Mientras, Para y SubProceso.
  • Inicialicé contadores y acumuladores antes de usarlos.
  • Probé mentalmente el algoritmo con un caso chico.
  • Revisé que las salidas coincidan con lo pedido.
C

Actividades de pseudocódigo

3 actividades · 1 punto cada una · se revisa la estructura del código.

10 Leé el nombre y la edad de una persona. Si tiene 18 años o más, mostrá <nombre> es mayor de edad; si no, <nombre> es menor de edad. Usá Si … Entonces … Sino … FinSi.

VariablesLeer / EscribirCondicional

Ver pista

Declará nombre como Caracter y edad como Entero. Leé los dos datos antes del Si. En cada rama, combiná el nombre con el texto usando comas dentro de Escribir.

Ver una solución de referencia 
Algoritmo EdadPersona
    Definir nombre Como Caracter;
    Definir edad Como Entero;
    Escribir "Ingresá el nombre:";
    Leer nombre;
    Escribir "Ingresá la edad:";
    Leer edad;
    Si edad >= 18 Entonces
        Escribir nombre, " es mayor de edad";
    Sino
        Escribir nombre, " es menor de edad";
    FinSi
FinAlgoritmo

11 Leé edades hasta que se ingrese 0. Contá cuántas personas son mayores de edad (18 años o más) y mostrá el total. Usá Mientras.

MientrasCondicionalContador

Ver pista

Inicializá un contador en 0 antes del bucle. Leé la primera edad antes del Mientras y volvé a leerla al final de cada vuelta. Dentro del bucle, usá un Si para incrementar el contador solo cuando la edad sea 18 o más.

Ver una solución de referencia 
Algoritmo ContarMayores
    Definir edad, mayores Como Entero;
    mayores <- 0;
    Escribir "Ingresá una edad (0 para terminar):";
    Leer edad;
    Mientras edad <> 0 Hacer
        Si edad >= 18 Entonces
            mayores <- mayores + 1;
        FinSi
        Escribir "Ingresá otra edad (0 para terminar):";
        Leer edad;
    FinMientras
    Escribir "Mayores de edad: ", mayores;
FinAlgoritmo

12 Creá un SubProceso llamado SumarHasta(limite) que sume los números del 1 al limite usando un Para y muestre el total. Llamalo desde el algoritmo principal con limite = 5.

SubProcesoParaAcumulador

Ver pista

El subproceso recibe un parámetro. Declará i y suma como enteros, inicializá suma en 0 y usá Para i <- 1 Hasta limite Con Paso 1 Hacer. Acumulá con suma <- suma + i;. Al final, llamá a SumarHasta(5); desde el Algoritmo principal.

Ver una solución de referencia 
SubProceso SumarHasta(limite)
    Definir i, suma Como Entero;
    suma <- 0;
    Para i <- 1 Hasta limite Con Paso 1 Hacer
        suma <- suma + i;
    FinPara
    Escribir "Total: ", suma;
FinSubProceso

Algoritmo SumaHastaCinco

FinAlgoritmo
