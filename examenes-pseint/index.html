Temario común

Las dos instancias evalúan exactamente los mismos nueve temas. Cambian las consignas y los contextos, no los contenidos ni la dificultad.

Algoritmos y programación estructurada Variables y tipos de datos Leer / Escribir Condicionales Mientras Para Contador Acumulador Subprocesos
TemaQué se espera
AlgoritmosReconocer las estructuras de secuencia, selección e iteración.
Variables y tiposDeclarar con Definir ... Como ...; y elegir Entero, Real, Caracter o Logico.
Leer / EscribirDiferenciar entrada y salida, y usarlas en el orden correcto.
CondicionalesEscribir Si ... Entonces ... Sino ... FinSi con la condición pedida.
MientrasRepetir mientras se cumple una condición y actualizar la variable de control.
ParaRecorrer un rango con inicio, fin y paso, incluyendo pasos negativos.
ContadorInicializar en 0 y sumar 1 en cada vuelta.
AcumuladorInicializar en 0 y sumar un valor variable en cada vuelta.
SubprocesosDeclarar SubProceso, recibir parámetros y llamarlo desde el algoritmo principal.

Cómo se corrige

ParteConsignaPuntos
A5 preguntas de opción múltiple5
B4 predicciones de salida2
C3 actividades de pseudocódigo3
Total10

La Parte C se corrige con una lista de requisitos. Cada actividad vale 1 punto y se otorga puntaje proporcional a los requisitos cumplidos. El corrector revisa la estructura del pseudocódigo: no ejecuta el programa.

Importante: las soluciones de referencia se muestran después de corregir. El objetivo es interpretar la lógica, no copiar una solución.

Antes de empezar

  • Leé la consigna completa antes de escribir.
  • Declará todas las variables con su tipo.
  • Cerrá cada Si, Mientras, Para y SubProceso.
  • Inicializá contadores y acumuladores antes de usarlos.
  • Probá mentalmente el algoritmo con un caso pequeño.
  • Revisá que la salida coincida con lo pedido.

Si una persona distinta va a usar la computadora, al terminar presioná Hacer otra evaluación. Así la página queda lista para el siguiente alumno.
