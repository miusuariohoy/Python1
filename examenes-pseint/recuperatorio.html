A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuál de estas estructuras es una selección?

La selección elige entre dos o más caminos según una condición. Mientras es una iteración; Leer y Definir son instrucciones simples.

2 ¿Qué tipo de dato conviene para guardar el nombre de un producto?

Caracter almacena texto. Entero y Real son numéricos; Logico solo admite Verdadero o Falso.

3 ¿Cuál instrucción muestra un mensaje en pantalla?

Escribir es la instrucción de salida. Leer es de entrada y necesita una variable; las otras opciones no son instrucciones válidas.

4 ¿Cuál es un bucle indeterminado, que no sabe de antemano cuántas veces se repetirá?

Mientras depende de una condición que puede cambiar. Para tiene inicio, fin y paso conocidos. Si no repite y SubProceso agrupa instrucciones.

5 En contador <- contador + 1;, ¿qué tipo de variable es contador?

El contador suma 1 en cada vuelta. El acumulador suma valores que pueden cambiar, por ejemplo total <- total + precio.

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir edad Como Entero;
edad <- 17;
Si edad >= 18 Entonces
    Escribir "Mayor";
Sino
    Escribir "Menor";
FinSi

17 es menor que 18, así que la condición es falsa y se ejecuta la rama del Sino: la salida es Menor.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
i <- 1;
Mientras i <= 4 Hacer
    Escribir i;
    i <- i + 1;
FinMientras

Muestra 1, 2, 3 y 4. Cuando i llega a 5, la condición i <= 4 es falsa y el bucle termina. La salida es 1 2 3 4.

8 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 5 Hasta 1 Con Paso -1 Hacer
    Escribir i;
FinPara

El paso negativo hace que el Para cuente hacia atrás. Muestra 5, 4, 3, 2 y 1. La salida es 5 4 3 2 1.

9 ¿Qué muestra este algoritmo?

SubProceso MostrarTabla(numero)
    Definir i Como Entero;
    Para i <- 1 Hasta 3 Con Paso 1 Hacer
        Escribir numero * i;
    FinPara
FinSubProceso

Algoritmo Prueba
    MostrarTabla(2);
FinAlgoritmo

El subproceso recibe 2 y muestra 2 * 1, 2 * 2 y 2 * 3. La salida es 2 4 6.

Cómo se corrige la Parte C

Cada actividad vale 1 punto y se evalúa con una lista de requisitos. Si falta un requisito, se descuenta la parte proporcional. El corrector revisa la estructura del pseudocódigo; no ejecuta el programa.

Se revisaEjemplo
Declaración de variables con tipoDefinir precio Como Real;
Entrada y salidaLeer precio; · Escribir precio;
Condicional completoSi ... Entonces ... Sino ... FinSi
Bucle completoMientras ... Hacer ... FinMientras
Contador o acumulador inicializadoaprobadas <- 0; · suma <- 0;

Antes de enviar

  • Declaré todas las variables con su tipo.
  • Cerré cada Si, Mientras, Para y SubProceso.
  • Inicialicé contadores y acumuladores antes de usarlos.
  • Probé mentalmente el algoritmo con un caso chico.
  • Revisé que las salidas coincidan con lo pedido.
C

Actividades de pseudocódigo

3 actividades · 1 punto cada una · se revisa la estructura del código.

10 Leé el nombre de un producto y su precio. Si el precio es mayor a 1000, mostrá <producto>: precio alto; si no, <producto>: precio accesible. Usá Si … Entonces … Sino … FinSi.

VariablesLeer / EscribirCondicional

Ver pista

Declará producto como Caracter y precio como Real. Leé los dos datos antes del Si. En cada rama, combiná el nombre del producto con el texto usando comas dentro de Escribir.

Ver una solución de referencia 
Algoritmo PrecioProducto
    Definir producto Como Caracter;
    Definir precio Como Real;
    Escribir "Ingresá el producto:";
    Leer producto;
    Escribir "Ingresá el precio:";
    Leer precio;
    Si precio > 1000 Entonces
        Escribir producto, ": precio alto";
    Sino
        Escribir producto, ": precio accesible";
    FinSi
FinAlgoritmo

11 Leé notas hasta que se ingrese -1. Contá cuántas notas son aprobadas (6 o más) y mostrá el total. Usá Mientras.

MientrasCondicionalContador

Ver pista

Inicializá un contador en 0 antes del bucle. Leé la primera nota antes del Mientras y volvé a leerla al final de cada vuelta. Dentro del bucle, usá un Si para incrementar el contador solo cuando la nota sea 6 o más.

Ver una solución de referencia 
Algoritmo ContarAprobadas
    Definir nota Como Real;
    Definir aprobadas Como Entero;
    aprobadas <- 0;
    Escribir "Ingresá una nota (-1 para terminar):";
    Leer nota;
    Mientras nota <> -1 Hacer
        Si nota >= 6 Entonces
            aprobadas <- aprobadas + 1;
        FinSi
        Escribir "Ingresá otra nota (-1 para terminar):";
        Leer nota;
    FinMientras
    Escribir "Aprobadas: ", aprobadas;
FinAlgoritmo

12 Creá un SubProceso llamado SumarPares(limite) que sume los números pares del 2 al limite usando un Mientras y muestre el total. Llamalo desde el algoritmo principal con limite = 10.

SubProcesoMientrasAcumulador

Ver pista

El subproceso recibe un parámetro. Declará i y suma como enteros, inicializá suma en 0 e i en 2. Repetí con Mientras i <= limite Hacer, acumulá suma <- suma + i; y avanzá con i <- i + 2;. Al final, llamá a SumarPares(10); desde el Algoritmo principal.

Ver una solución de referencia 
SubProceso SumarPares(limite)
    Definir i, suma Como Entero;
    i <- 2;
    suma <- 0;
    Mientras i <= limite Hacer
        suma <- suma + i;
        i <- i + 2;
    FinMientras
    Escribir "Total: ", suma;
FinSubProceso

Algoritmo SumaParesHastaDiez
    SumarPares(10);
FinAlgoritmo
