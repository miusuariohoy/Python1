1 Variables y tipos de datos

Una variable es una caja etiquetada donde el programa guarda un dato para usarlo después. El signo = no significa "igual" como en matemática: significa guardá esto acá adentro.

Sintaxis nombre_variable = valor
Asignación y tipos
nombre = "Ana"       # str   (texto)
edad = 15           # int   (entero)
altura = 1.62        # float (decimal)
aprobado = True     # bool  (verdadero/falso)
  • str: texto entre comillas. Puede tener letras, números y símbolos.
  • int: número entero, sin coma decimal.
  • float: número con parte decimal (se escribe con punto).
  • bool: solo dos valores posibles: True o False.
La caja cambia: edad = edad + 1 toma lo que había, le suma 1 y vuelve a guardar el resultado en la misma caja.

Buena práctica: en Python el tipo se deduce solo (no se declara como en otros lenguajes), pero conviene que cada variable guarde siempre el mismo tipo de dato para no confundirse.

2 Ingreso y salida de datos

Todo programa interactivo hace lo mismo: ingresa un dato (input()), procesa y muestra el resultado (print()). Ojo: input() siempre devuelve texto (str), aunque escriban números.

Entrada sola: input()

Cuando el programa solo necesita pedir un dato, alcanza con input(). El valor queda guardado en una variable y no se muestra nada más: 

nombre = input("¿Cómo te llamás? ")
# la entrada terminó: el dato quedó guardado en nombre
FunciónConvierte aEjemplo
int()enteroint("15") -> 15
float()decimalfloat("1.75") -> 1.75
str()textostr(21) -> "21"
Salida sola: print() y f-strings

Cuando el dato ya está resuelto, print() lo muestra sin pedir nada por teclado: 

print("Hola")                  # texto fijo
print("Hola", nombre)          # separa con espacio
print(f"El doble es {doble}")  # f-string: mete variables adentro
  • La f antes de las comillas permite poner variables entre llaves sin cortar el texto.
  • Sin la f, las llaves se muestran como texto común.
  • print(a, b) separa los valores con un espacio.
Entrada y salida juntas: leer → calcular → mostrar

Lo más habitual es combinar las dos: input() pide, el programa calcula y print() muestra el resultado. 

numero = int(input("Ingrese un número: "))
doble = numero * 2
print(f"El doble es {doble}")
Error clásico: "2" + "3" da "23" (concatena texto) porque input trajo str. Sin int(), el programa corre pero calcula mal.
Buenas prácticas con input:
  1. Mensaje claro que diga qué dato se espera.
  2. Convertí apenas leés: int(input(...)).
  3. Si puede fallar la conversión, protegé con try / except.
Módulos y pausas: import time

Además de los datos, un programa puede usar módulos: archivos con funciones ya hechas que se cargan con import. Uno muy útil es time, que permite hacer pausas y medir tiempo. 

import time

print("Inicio")
time.sleep(2)          # espera 2 segundos
print("Pasaron 2 segundos")
  • import time carga el módulo. Va al principio del archivo.
  • time.sleep(segundos) detiene el programa esa cantidad de segundos.
  • Se usa para simulaciones o pausas en programas de consola. En Tkinter no se usa: congela la ventana (allí se usa after()).
Ojo: sleep() no “hace varias cosas a la vez”: el programa queda esperando. No lo uses para repetir tareas ni dentro de ventanas gráficas.

3 Toma de decisiones: if / elif / else

Un programa casi nunca hace siempre lo mismo: tiene que decidir. Pensalo como una bifurcación en el camino: según una condición (verdadera o falsa), el programa toma un camino u otro.

    instrucciones
elif otra_condicion:
    # se ejecuta si la primera fue False y esta es True
    instrucciones

    # si nada anterior se cumplió

  • Línea 1: se evalúa la condición. Si es verdadera, entra al bloque con sangría.

4 Contador y acumulador: dos variables que crecen

Un contador y un acumulador son variables que empiezan con un valor inicial (casi siempre 0) y van cambiando a medida que el programa hace su trabajo. La diferencia está en qué les sumamos.

Sintaxis variable = valor_inicial
variable = variable + algo
variable += algo     # forma abreviada
Contador: cuenta cuántas veces pasa algo

Al contador siempre se le suma 1 (o un paso fijo). Sirve para responder ¿cuántos?: cuántos alumnos aprobaron, cuántos intentos hubo, cuántas ventas se hicieron. 

clics = 0              # arranca en cero
clics = clics + 1       # primer clic
clics = clics + 1       # segundo clic
print(clics)             # 2
Atajo: clics += 1 hace exactamente lo mismo que clics = clics + 1. Se lee “a clics sumale 1”.
Acumulador: suma valores que cambian

Al acumulador se le suma un valor distinto cada vez. Sirve para responder ¿cuánto en total?: la suma de las notas, el total de una compra, la recaudación del día. 

total = 0              # arranca vacío
total = total + 1500    # suma una yerba
total = total + 750     # suma un pan
total = total + 2000    # suma un queso
print(total)            # 4250
Atajo: total += 750 equivale a total = total + 750.
Comparación rápida
ContadorAcumulador
¿Qué guarda?una cantidad de vecesuna suma de valores
¿Qué suma?siempre 1 (o un paso fijo)un valor que cambia
Arranca en0 (o 1 si empieza a contar desde 1)0

Ejemplo“aprobaron 18 alumnos”“se recaudaron $45.000”
Error clásico: inicializar la variable dentro de un bucle. Si total = 0 se ejecuta en cada vuelta, se borra lo acumulado. La inicialización va antes de empezar a contar o acumular.
Buena práctica: usá nombres que expliquen qué cuentan: aprobados, intentos, total_compra. Evitá x o c.

5 Bucle for: repetir una cantidad conocida de veces

El for repite un bloque de instrucciones una vez por cada valor de una secuencia. Se usa cuando sabemos de antemano cuántas vueltas hay que dar: mostrar los números del 1 al 10, recorrer una lista o generar una tabla de multiplicar.

Sintaxis for variable in range(inicio, fin, paso):
    instrucciones 
for i in range(1, 6):
    print(i)              # muestra 1, 2, 3, 4 y 5
range(): el generador de números
EscrituraValores que toma la variableVueltas
range(5)0, 1, 2, 3, 45
range(1, 6)1, 2, 3, 4, 55
range(0, 10, 2)0, 2, 4, 6, 85
range(5, 0, -1)5, 4, 3, 2, 15
Regla de oro: range(inicio, fin) incluye el inicio pero nunca incluye el fin. Para llegar al 10 hay que escribir range(1, 11).
Ejemplo: la tabla del 7
for i in range(1, 11):
    print(f"7 x {i} = {7 * i}")

La variable i cambia sola en cada vuelta: no hace falta incrementarla a mano. El cuerpo del for debe ir con sangría y la línea del for termina en dos puntos.

For + acumulador: sumar del 1 al 10
total = 0
for i in range(1, 11):
    total += i
print("La suma es", total)   # 55
Errores típicos: olvidar los dos puntos, no poner sangría, usar range(1, 10) cuando se necesita el 10, o intentar cambiar i dentro del for (el for vuelve a asignarla en cada vuelta).

6 Bucle while: repetir mientras se cumpla una condición

El while repite un bloque mientras una condición sea verdadera. Se usa cuando no sabemos cuántas vueltas habrá: depende de lo que escriba el usuario o de cuándo se cumpla una condición.

Sintaxis while condición:
    instrucciones
Idea clave: algo dentro del while tiene que cambiar para que la condición llegue a ser falsa. Si nada cambia, el ciclo nunca termina: bucle infinito.
Forma 1 · while fijo (controlado por un contador)

Sabemos cuántas vueltas queremos. Inicializamos un contador, lo comparamos en la condición y lo actualizamos dentro del ciclo. 

i = 1                  # inicialización
while i <= 5:          # condición
    print("Vuelta", i)
    i += 1             # actualización: sin esto, infinito
Forma 2 · while con condición (centinela)

No sabemos cuántas vueltas serán: el ciclo termina cuando el dato cumple algo (por ejemplo, cuando el usuario escribe 0 o la clave correcta). Ese valor que marca el final se llama centinela. 

suma = 0
numero = int(input("Número (0 para salir): "))
while numero != 0:
    suma += numero
    numero = int(input("Número (0 para salir): "))
print("Suma total:", suma)
Ojo: en el while con centinela hay que volver a leer el dato dentro del ciclo. Si solo se lee antes, la condición nunca cambia y el programa se queda repitiendo para siempre.
break: cortar el ciclo desde adentro
while True:
    opcion = input("Opción (S para salir): ")
    if opcion == "S":
        break              # abandona el while inmediatamente
    print("Elegiste:", opcion)

9 return, print y alcance de las variables

print() muestra un valor en pantalla; return devuelve un valor al programa para que lo guarde o lo siga usando. No son lo mismo: una función puede mostrar algo sin devolver nada, o devolver un resultado sin mostrarlo.

Sintaxis def nombre(parámetros):
    instrucciones
    return resultado 
def sumar(a, b):
    return a + b          # devuelve el valor, no lo muestra

resultado = sumar(4, 6)  # guarda 10
print(resultado)         # recién acá se muestra 10
Diferencias entre print y return
print()return
¿Qué hace?muestra en pantallaentrega un valor al programa
¿Se puede guardar?nosí: x = funcion()
¿Sirve para seguir calculando?nosí
¿Termina la función?nosí, vuelve inmediatamente
Si no estáno muestra nadala función devuelve None
Truco para recordarlo: print es hablar por altavoz; return es entregar un papel con el resultado en la mano.
Variables locales

Una variable local nace dentro de una función y solo existe ahí. Cuando la función termina, la variable desaparece. 

def calcular():
    temporal = 10       # local: solo vive dentro de calcular
    return temporal * 2

print(calcular())      # 20
# print(temporal)     # error: temporal no existe acá afuera
Variables globales

Una variable global se define fuera de las funciones y se puede leer desde cualquier función. Para modificarla hay que avisarlo con la palabra global. 

contador = 0              # global

def sumar_uno():
    global contador        # permiso para modificarla
    contador += 1

sumar_uno()
print(contador)          # 1
Cuidado: abusar de global hace que el programa sea difícil de seguir. Lo recomendado es pasar los datos por parámetros y devolver el resultado con return.

11 Manejo de errores con try / except

Un programa bien hecho no debería cerrarse de golpe cuando el usuario escribe algo inesperado. try / except permite intentar una operación peligrosa y, si falla, ejecutar un plan B en lugar de terminar con un error.

Sintaxis try:
    instrucciones que pueden fallar
except TipoDeError:
    plan B 
try:
    numero = int(input("Número: "))
    print("El doble es", numero * 2)
except ValueError:
    print("Eso no es un número válido")
Errores frecuentes
ErrorCuándo apareceEjemplo
ValueErrorno se puede convertir el texto a númeroint("hola")
ZeroDivisionErrorse intenta dividir por cero10 / 0
NameErrorse usa una variable que no existeprint(tottal)
IndexErrorse pide una posición que no existelista[99]
Atrapar un error específico
try:
    a = int(input("Dividendo: "))
    b = int(input("Divisor: "))
    print(a / b)
except ZeroDivisionError:
    print("No se puede dividir por cero")
Buena práctica: atrapá el error más específico que esperás (ValueError, ZeroDivisionError) y mostrá un mensaje claro. Evitá un except vacío que oculte cualquier problema.
Ojo: try / except no corrige el error; permite reaccionar sin que el programa se cierre. La validación sigue siendo necesaria.
