1 Variables y tipos de datos

Una variable es una caja etiquetada donde el programa guarda un dato para usarlo después. El signo = no significa "igual" como en matemática: significa guardá esto acá adentro.

Sintaxis nombre_variable = valor
Asignación y tipos
nombre = "Ana"       # str   (texto)
edad = 15           # int   (entero)
altura = 1.62        # float (decimal)
aprobado = True     # bool  (verdadero/falso)
  • str: texto entre comillas. Puede tener letras, números y símbolos.
  • int: número entero, sin coma decimal.
  • float: número con parte decimal (se escribe con punto).
  • bool: solo dos valores posibles: True o False.
La caja cambia: edad = edad + 1 toma lo que había, le suma 1 y vuelve a guardar el resultado en la misma caja.
Reglas para los nombres

Buena práctica: en Python el tipo se deduce solo (no se declara como en otros lenguajes), pero conviene que cada variable guarde siempre el mismo tipo de dato para no confundirse.

2 Ingreso y salida de datos

Todo programa interactivo hace lo mismo: ingresa un dato (input()), procesa y muestra el resultado (print()). Ojo: input() siempre devuelve texto (str), aunque escriban números.

Patrón dato = int(input("Mensaje: "))
resultado = dato * 2
print(f"El doble es {resultado}")
Ingreso: input() y conversiones

Salida: print() y f-strings

print(f"El doble es {doble}")  # f-string: mete variables adentro
print(f"{n}x{i}={n*i}")         # así se arman las tablas
  • La f antes de las comillas permite poner variables entre llaves sin cortar el texto.
  • Sin la f, las llaves se muestran como texto común.
  • print(a, b) separa los valores con un espacio.
Patrón completo
# leer - convertir - calcular - mostrar
numero = int(input("Ingrese un número: "))
doble = numero * 2
print(f"El doble es {doble}")
Error clásico: "2" + "3" da "23" (concatena texto) porque input trajo str. Sin int(), el programa corre pero calcula mal.
Buenas prácticas con input:
  1. Mensaje claro que diga qué dato se espera.
  2. Convertí apenas leés: int(input(...)).
  3. Si puede fallar la conversión, protegé con try / except.

3 Toma de decisiones: if / elif / else

Un programa casi nunca hace siempre lo mismo: tiene que decidir. Pensalo como una bifurcación en el camino: según una condición (verdadera o falsa), el programa toma un camino u otro.

Sintaxis general if condición:
    instrucciones
elif otra_condición:
    instrucciones
else:
    instrucciones 
if condicion:
    # se ejecuta solo si la condicion es True
    instrucciones
elif otra_condicion:
    # se ejecuta si la primera fue False y esta es True
    instrucciones
else:
    # si nada anterior se cumplió
    instrucciones
  • Línea 1: se evalúa la condición. Si es verdadera, entra al bloque con sangría.
  • elif: se prueba solo si la anterior falló. Podés encadenar varios.
  • else: es el "si no se cumplió nada". Va al final y sin condición.

4 Ciclos: while, for, contador y acumulador

El while repite un bloque mientras una condición siga siendo verdadera. Analogía: mientras llueva, quedate bajo el techo; cuando pare, salí.

Sintaxis while condición:
    instrucciones
Idea clave: algo dentro del ciclo tiene que cambiar para que la condición en algún momento sea False. Si nada cambia: ciclo infinito.
Forma 1: con contador (sabés cuántas vueltas)
i = 1
while i <= 5:
    print("Vuelta", i)
    i = i + 1            # sin esta línea: bucle infinito
Forma 2: con centinela (no sabés cuántas vueltas)
clave = ""
while clave != "1234":
    clave = input("Clave: ")
print("Acceso permitido")
for: cuando sabés cuántas vueltas
for i in range(1, 11):
    print(f"7 x {i} = {7*i}")   # la tabla del 7, completa

range(0, 10, 2)0, 2, 4, 6, 8  (tercer dato = paso)

total = 0                          # acumulador, arranca vacío
aprobados = 0                      # contador

for i in range(3):
    nota = int(input("Nota: "))
    total = total + nota           # acumula: suma CADA nota

        aprobados = aprobados + 1  # cuenta UNO más

Error clásico: olvidar inicializar antes del ciclo. Si total = 0 está DENTRO del for, se borra en cada vuelta y al final vale solo la última nota.
break: corta el ciclo en el momento
while True:              # bucle "infinito" a propósito
    opcion = input("Opción (S para salir): ")
    if opcion == "S":
        break             # abandona el while acá mismo
    print("Elegiste:", opcion)
print("Fin del programa")
Buena práctica: el patrón while True + break es el estándar para menús. Deja la condición de salida junta con la lectura del dato.

5 Modularización: funciones con def

Una función es una caja con nombre que guarda instrucciones para reutilizarlas. Analogía: la receta de unas tortas fritas se escribe una vez y se usa cada vez que haga falta.

Sintaxis def nombre(parámetros):
    instrucciones
    return resultado
Partes de una función
def es_par(n):                # def + nombre + (parámetros):
    if n % 2 == 0:        # cuerpo (con sangría)
        return True       # devuelve un valor a quien llamó
    else:
        return False

resultado = es_par(8)         # llamada: el valor queda en resultado
print(resultado)               # True
Definir no es ejecutar: el cuerpo corre recién cuando alguien llama a la función por su nombre.
Parámetros y argumentos
ConceptoQué esDónde viveEjemplo
Parámetrola variable que la función recibeen la definicióndef tabla(n):
Argumentoel valor concreto enviadoen la llamadatabla(7)
def tabla(n):                  # n es el parámetro
    for i in range(1, 11):
        print(f"{n}*{i}={n*i}")

tabla(7)                       # 7 es el argumento
Valor por defecto (default)
def saludo(nombre="mundo"):
    print("Hola", nombre)

saludo("Ana")     # Hola Ana
saludo()           # Hola mundo   (usa el default)

Un parámetro puede traer un valor precargado: si la llamada no lo envía, se usa ese.

return: devolver un resultado
def area_rectangulo(base, altura):
    return base * altura

a = area_rectangulo(5, 3)   # a vale 15
printreturn
Qué hacemuestra en pantallaentrega el valor al programa
Se puede guardarnosí: x = funcion()
Sirve para seguir calculandonosí
Sin return: toda función devuelve None aunque tenga print. Print muestra; return entrega.
Variables locales y globales
  • Local: nace dentro de la función, muere al terminar.
  • Global: nace fuera; todas las funciones pueden leerla.
  • Para modificarla dentro de una función hay que declarar global.
intentos = 0                 # global

def sumar_intento():
    global intentos
    intentos = intentos + 1
Buena práctica: usá global solo cuando sea necesario; lo ideal es pasar datos por parámetros y recibir resultados con return.

6 Integración: interfaz con Tkinter

Hasta acá el programa conversaba por consola. Con Tkinter (viene incluido en Python) armamos ventanas con etiquetas, campos y botones: el usuario interactúa y el programa reacciona a eventos.

Ventana base
from tkinter import *

ventana = Tk()
ventana.title("Mi app")
ventana.geometry("400x300")

ventana.mainloop()      # deja la ventana viva, escuchando eventos
mainloop() es el motor: un ciclo oculto que espera clicks y teclas para disparar las funciones que indicaste.

Error clásico Nº1: command=verificar() con paréntesis ejecuta la función UNA vez al crear el botón y luego no hace nada. Sin paréntesis (command=verificar) entregás la función para que el click la llame. Si necesitás enviarle datos: command=lambda: tabla(7).

Truco pro: after agenda UNA sola ejecución. Para repetir, la función se llama de nuevo al final (se re-agenda). Es como tirar la pelota contra la pared: cada rebote vuelve a programar el próximo.

Reglas de oro de Tkinter
  1. Nada de while ni input() dentro de una app de ventanas: bloquean el mainloop. El reemplazo del while es after(); el del input es el Entry.
  2. Los datos viven en widgets: .get() para leer, .config() para cambiar, .delete(0, END) para vaciar.
  3. El botón lleva la función SIN paréntesis; con datos, usá lambda.
  4. Si una función cambia una variable global, declará global.
  5. mainloop() siempre al final del archivo.
