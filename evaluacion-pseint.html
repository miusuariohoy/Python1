A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuáles son las tres estructuras de control de la programación estructurada?

La programación estructurada se organiza con secuencia (una instrucción tras otra), selección (Si–Entonces) e iteración (Mientras / Para).

2 ¿Qué hace la línea Definir edad Como Entero;?

Declarar es reservar la variable e indicar su tipo. El valor se asigna después con la flecha <-.

3 ¿Cuál es la diferencia entre Leer y Escribir?

Leer es la entrada (pausa el programa y guarda lo que escribe el usuario) y Escribir es la salida (muestra información).

4 ¿Cuándo conviene usar un bucle Para en lugar de un Mientras?

El Para es un bucle determinado: sabemos el inicio y el fin. El Mientras depende de una condición que puede cambiar, como un menú que termina cuando el usuario elige salir.

5 ¿En qué se diferencian un contador y un acumulador?

Contador: c <- c + 1. Acumulador: suma <- suma + valor, donde valor cambia en cada vuelta.

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir nota Como Real;
nota <- 8;
Si nota >= 6 Entonces
    Escribir "Aprobado";
Sino
    Escribir "Desaprobado";
FinSi

Como 8 es mayor o igual que 6, la condición es verdadera y se ejecuta la rama del Entonces: la salida es Aprobado.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 1 Hasta 3 Con Paso 1 Hacer
    Escribir i;
FinPara

El bucle Para recorre 1, 2 y 3 (el 3 está incluido). La salida es 1 2 3 (uno por línea).

8 ¿Qué muestra este algoritmo?

Definir c Como Entero;
c <- 3;
Mientras c > 0 Hacer
    Escribir c;
    c <- c - 1;
FinMientras

El bucle muestra 3, luego 2 y luego 1. Cuando c llega a 0 la condición deja de cumplirse. La salida es 3 2 1.

9 ¿Qué muestra este algoritmo?

Definir suma, i Como Entero;
suma <- 0;
Para i <- 1 Hasta 4 Con Paso 1 Hacer
    suma <- suma + i;
FinPara
Escribir suma;

suma es un acumulador: 1 + 2 + 3 + 4 = 10. La salida es 10.

11 Leé la edad de una persona y mostrá Mayor de edad si tiene 18 años o más, y Menor de edad si no. Usá Si … Entonces … Sino … FinSi.

Ver una solución de referencia 
Algoritmo EdadPersona
    Definir edad Como Entero;
    Escribir "Ingresá la edad:";
    Leer edad;
    Si edad >= 18 Entonces
        Escribir "Mayor de edad";
    Sino
        Escribir "Menor de edad";
    FinSi
FinAlgoritmo
