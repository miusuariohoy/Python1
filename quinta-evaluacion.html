A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cómo se borra todo el contenido de un widget Text?

Text usa notación línea.carácter: "1.0" es línea 1, carácter 0.

2 ¿Qué es una lambda en Python?

lambda x: x * 2 equivale a una función def que devuelve x * 2.

3 Con command=lambda: mostrar_tabla(7), ¿cuándo se ejecuta mostrar_tabla(7)?

Tkinter guarda la mini-función y la llama recién en el click, con el dato incluido.

4 ¿Qué significa state=DISABLED en un botón?

El control se muestra gris y no responde hasta que se habilita con state=NORMAL.

5 ¿Cómo volvés a habilitar un botón bloqueado?

La forma correcta es boton.config(state=NORMAL).

B

Predicción de salidas

4 programas · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este programa?

doble = lambda x: x * 2
print(doble(6))

La lambda devuelve 6 × 2: 12.

7 ¿Qué muestra este programa?

suma = lambda a, b: a + b
print(suma(3, 4))

La lambda recibe dos parámetros y devuelve 3 + 4: 7.

8 ¿Qué muestra este programa?

texto = "hola\n"
print(len(texto))

El salto de línea \n cuenta como un carácter: 4 letras + 1 = 5.

9 ¿Qué muestra este programa?

estado = "disabled"
print(estado.upper())

upper() devuelve DISABLED (se acepta en minúsculas).

C

Ejercicios de código

2 programas · 1,5 puntos cada uno · se corrige la estructura del código.

10 Creá una ventana con un widget Text empaquetado con pack() y definí agregar(tarea) que inserte la tarea al final con insert(END, ...) y un salto de línea \n. Cerrá con mainloop().

Ver una solución de referencia 
from tkinter import *

ventana = Tk()
texto = Text(ventana)
texto.pack()

def agregar(tarea):
    texto.insert(END, tarea + "\n")

agregar("Comprar pan")
ventana.mainloop()

11 Definí saludar(nombre) con un parámetro y un Button con command=lambda: saludar("Ana"). Además creá un botón Guardar con state=DISABLED y una función que lo habilite con config(state=NORMAL), conectada con command. Cerrá con mainloop().

Ver una solución de referencia 
from tkinter import *

ventana = Tk()

boton_guardar = Button(ventana, text="Guardar", state=DISABLED)
boton_guardar.pack()

def habilitar():
    boton_guardar.config(state=NORMAL)

Button(ventana, text="Habilitar", command=habilitar).pack()

def saludar(nombre):
    print(nombre)

Button(ventana, text="Ana", command=lambda: saludar("Ana")).pack()

ventana.mainloop()
